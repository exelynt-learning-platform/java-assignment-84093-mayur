# Git & GitHub Version Control Project

## Project Overview

This project demonstrates the basic Git and GitHub workflow, including repository management, commits, branching, merging, merge conflict resolution, and remote repository management.

## Setup Steps

1. Clone the repository.
2. Open the project folder in VS Code.
3. Create and modify project files as required.
4. Use Git to track changes.
5. Create branches for new features.
6. Commit changes with meaningful commit messages.
7. Merge the feature branch into the assignment branch.
8. Push the changes to GitHub.

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.

Alternatively, run the project using a local static server and open the provided local URL in your browser.
