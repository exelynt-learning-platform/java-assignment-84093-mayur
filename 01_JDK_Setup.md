# Java JDK Installation and PATH Configuration

## 1. Objective

The objective of this task is to install the Java Development Kit (JDK) and configure the PATH environment variable so that Java commands can be executed from the Windows Command Prompt.

## 2. Requirements

- Java Development Kit (JDK)
- Windows Operating System
- Command Prompt

## 3. Installation Steps

### Step 1: Download JDK

The Java Development Kit (JDK) was downloaded and installed on the system.

### Step 2: Install JDK

The JDK installation was completed using the installation wizard.

### Step 3: Configure PATH

The JDK `bin` directory was added to the system PATH environment variable.

The PATH environment variable allows Java commands to be executed from any location in the Command Prompt.

### Step 4: Verify Java Installation

Command Prompt was opened and the following command was executed:

```cmd
java --version
```

The installed Java version was displayed successfully.

## 4. Java Program

The following Java program was created to verify that the Java development environment is working correctly:

```java
package aadi;

public class Demo {
    public static void main(String[] args) {
        System.out.println("Java Setup Successful");
    }
}
```

## 5. Program Output

After running the Java program, the following output was displayed:

```text
Java Setup Successful
```

This confirms that Java is installed correctly and the program can be compiled and executed successfully.

## 6. Verification

The Java environment was verified by:

- Checking the installed Java version using `java --version`.
- Confirming that the JDK is accessible from Command Prompt.
- Running a simple Java program.
- Confirming the expected program output.

## 7. Result

Java JDK was successfully installed and the PATH environment variable was configured correctly. The Java program also executed successfully and displayed the expected output.
