# Java JDK Installation and PATH Configuration

## 1. Objective

The objective of this task is to install the Java Development Kit (JDK) and configure the PATH environment variable so that Java commands can be executed from the Command Prompt.

## 2. Requirements

- Java Development Kit (JDK)
- Windows Operating System
- Command Prompt

## 3. Installation Steps

### Step 1: Download JDK

The Java Development Kit was downloaded and installed on the system.

### Step 2: Install JDK

The JDK installation was completed using the installation wizard and the default installation settings.

### Step 3: Configure PATH

The JDK `bin` directory was added to the system PATH environment variable.

The PATH allows Java commands to be executed from any location in the Command Prompt.

### Step 4: Verify Java Installation

Command Prompt was opened and the following command was executed:

```bash
java --version
```

The installed Java version was displayed successfully.

## 4. Verification

The Java version was displayed in the Command Prompt, confirming that:

- JDK is installed correctly.
- Java is accessible from the Command Prompt.
- PATH is configured correctly.

## 5. Result

Java JDK was successfully installed and the PATH environment variable was configured correctly.
