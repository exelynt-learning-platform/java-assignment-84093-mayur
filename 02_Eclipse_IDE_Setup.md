## 1. Objective

The objective of this task is to install Eclipse IDE, create a Java project, create a Java class, and run a simple Java program successfully.

## 2. Requirements

- Java JDK
- Eclipse IDE
- Windows Operating System

## 3. Eclipse IDE Installation

### Step 1: Download Eclipse IDE

Eclipse IDE was downloaded and installed on the system.

### Step 2: Launch Eclipse

After installation, Eclipse IDE was opened and a workspace location was selected.

## 4. Creating a Java Project

A new Java project was created in Eclipse.

- **Package Name:** `Aadi`
- **Class Name:** `Demo`

## 5. Creating the Java Program

The following Java program was written in the `Demo` class:

```java

public class Demo {

        System.out.println("Java Setup Successful");
```

## 6. Running the Program

The Java program was executed using Eclipse IDE.

The program ran successfully without any compilation or runtime errors.
